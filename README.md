# FantasyEarthZero-building

FantasyEarthZero building data

建築物モデル **22種 / 84モデル** を収録しています。各モデルは Blender 用 (`Blender/*.blend`) と元データ (`Model/*.mdl`, `*.tex`, `*.anm`) があります。

> プレビュー画像は各 .blend を Blender 5.2 (EEVEE) で自動レンダリングしたものです（正面やや右上から）。
> `_hit` / `_m` / `_s` / `_stand` / `_light` / `_null` はゲーム内仕様用のファイルのため一覧から省いています。
